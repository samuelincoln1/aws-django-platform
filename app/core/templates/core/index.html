This Django application provides a simple CRUD (Create, Read, Update, Delete) interface for managing items in a database table. Users can add new items, view all existing items with their creation and modification timestamps, edit items, and delete as needed. The interface displays real-time feedback for all operations performed on the data.

This comprehensive Django application showcases enterprise-grade AWS cloud architecture and DevOps best practices. The application connects to a highly available PostgreSQL RDS database configured with Multi-AZ deployment for automatic failover and disaster recovery. The backend runs on a minimum of 4 auto-scaling ECS Fargate containers distributed across two availability zones, ensuring high availability and fault tolerance.

Following security best practices, all application components are deployed in private subnets with no direct internet access. Static files (CSS, JavaScript, images) are served efficiently from Amazon S3. The entire infrastructure is provisioned as code using Terraform, featuring secure networking with VPC endpoints, AWS Secrets Manager for credential management, and comprehensive logging with CloudWatch. Traffic is routed through an Application Load Balancer with SSL/TLS termination, automatic HTTP to HTTPS redirection, and custom domain configuration.
